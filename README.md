## 🚀 What I'm Building

### 🔄 Self-Healing Data Pipeline Agent
[github.com/chahakgoswami/self-healing-data-pipeline-agent](https://github.com/chahakgoswami/self-healing-data-pipeline-agent)

An agentic ETL system that detects schema drift, drafts corrective actions, validates fixes, and recovers safely from failures.

Highlights:
- Schema drift detection
- Automated fix generation
- Human-in-the-loop approval
- Sandboxed execution
- Automatic rollback
- Structured audit logging
- 130+ automated tests

The goal is to explore how AI agents can make data systems more resilient without giving up safety or control.

### 🔎 Deep Research Agent with Citation Graph
[github.com/chahakgoswami/deep-research-agent-citation-graph](https://github.com/chahakgoswami/deep-research-agent-citation-graph)

A multi-hop research agent designed around one problem: making AI-generated research more trustworthy.

Highlights:
- Multi-step research planning
- Citation graph generation
- Source grading
- Contradiction detection
- Evidence tracking
- Human-controlled file output

Instead of simply generating an answer, the system makes it easier to understand where conclusions came from and how strong the supporting evidence is.

---

### 🎫 Autonomous Ticket Resolution Engine
[github.com/chahakgoswami/autonomous-ticket-resolution-engine](https://github.com/chahakgoswami/autonomous-ticket-resolution-engine)

An autonomous support agent that reads tickets, retrieves relevant data, creates an action plan, applies approved fixes, and produces an auditable resolution record.

Highlights:
- Ticket intent analysis
- Automated query execution
- Action planning
- Safe vs. destructive action classification
- Human approval for destructive actions
- Automated resolution workflow
- JSON audit trail
- End-to-end testing

The project explores how agents can automate repetitive support tasks while keeping higher-risk actions under human control.
